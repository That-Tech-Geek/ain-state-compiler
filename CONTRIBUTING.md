# Contributing to AIN State Compiler

Thank you for your interest in contributing.

## Before You Contribute

By submitting a pull request or any code contribution to this repository,
you agree that:

1. Your contribution becomes the sole property of Sambit Mishra.
2. You have the right to submit the code and it doesn't violate any
   third-party IP.
3. You will not be compensated for contributions unless agreed in writing.

This is standard practice for proprietary source-available projects.

## How to Contribute

- Open an issue first describing the bug or feature
- Wait for acknowledgment before writing code
- Keep PRs small and focused on one thing

## What We're Looking For

- Bug fixes in the sync and compile pipeline
- Edge case handling in conflict_detector.py
- Platform-specific cron issues (Windows especially)
- Documentation improvements
